# Samsung Health Data SDK

This directory is intentionally excluded from source control except for this README.

## Required file

Place the official Samsung Health Data SDK AAR here:

```
samsung-health-data-api-1.1.0.aar
```

Expected path:

```
feature/training/libs/samsung-health-data-api-1.1.0.aar
```

## Where to get it

Download the SDK from Samsung Developer:

https://developer.samsung.com/health/data/overview.html

The AAR is included inside the downloaded ZIP package.

## Why it is not committed

The Samsung Health Data SDK is distributed by Samsung and is not available from Maven Central. We keep the binary out of Git and each developer downloads the official copy directly from Samsung.
